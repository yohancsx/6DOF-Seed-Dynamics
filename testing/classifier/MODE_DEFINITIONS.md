# Flight-mode definitions

The single reference for what every mode label means, in words and mathematically.

- **The six-part classifier** (sections 1–3) is the current definition. It is implemented in:
  - `testing/helpers/classifySeedMode.m`: the decision rules;
  - `testing/helpers/defaultSeedModeThresholds.m`: every boundary value;
  - `testing/helpers/computeSeedModeMetrics.m`: the measurements.

  **Keep this file and those three in step**: a boundary that changes in the code changes
  here, with its date.
- **Use the mode names in section 3** when labelling by eye. Section 6 is the template for
  adding a mode.
- **To see what each mode looks like**, open `Outputs/Mode Examples/INDEX.md`: one
  idealized animation per name, generated by `testing/classifier/makeModeExamples.m`.
- **Sections 4–5 transcribe the two older classifiers** (`classifyFlightMode`,
  `classifyPaperMode`). They are kept for comparison with earlier runs.

Body axes: `x` = chord, `y` = plate normal, `z` = span. World `Y` is up. `R(t)` is the
body→world rotation. Every metric is computed over the **settled window**
`W = { t : t ≥ 0.5·t_end }`; for a 12 s drop that is the last 6 s.

## 1. Measurements (`computeSeedModeMetrics`)

Unit vectors in the world frame:

| symbol | definition | meaning |
|---|---|---|
| $\hat n$ | $R\,\hat e_y$ | plate normal |
| $\hat s$ | $R\,\hat e_z$ | span axis, $+z$ = nut side |
| $\hat Y$ | $(0,1,0)$ | world vertical |

| metric | definition |
|---|---|
| span tilt $\theta$ | $\arcsin(\hat s\cdot\hat Y)$: span axis from horizontal. `absSpanTiltDeg` = mean $\lvert\theta\rvert$; `spanAxisTiltStd` = std of $\theta$ |
| flip angle $\psi$ | the plate normal's angle about the span axis, referenced to "up". With $e_1=\mathrm{unit}(\hat Y-(\hat Y\cdot\hat s)\hat s)$ and $e_2=\hat s\times e_1$: $\psi=\mathrm{atan2}(\hat n\cdot e_2,\ \hat n\cdot e_1)$, unwrapped. Taken from **attitude**: a steady revolution leaves it constant, a tumble advances it $2\pi$ per turn, a flutter makes it oscillate. Undefined only for a vertical span (end-on, caught first). |
| `flipPPTurns` | $(\max\psi-\min\psi)/2\pi$ |
| `flipMaxTurnsOneWay` | longest one-way leg of $\psi$ between reversals, in turns |
| `flipReversals` | reversals of $\psi$; $\psi$ must retreat **0.25 turn** from its running extreme to count |
| `flipReversalCV` | std / mean of the time between reversals (needs ≥ 3 reversals) |
| `spanHeadingRate` $\dot\phi_s$ | slope of the span axis's horizontal heading, $\mathrm{atan2}(-s_Z, s_X)$, measured about $+\hat Y$: the **revolution rate**, from attitude. A tumble or flutter leaves the heading fixed however the span is tilted. (The body's spin about the vertical does not: a tilted tumble projects onto it.) |
| `radiusPerSpan` | radius of a circle fit to the CoM ground track, divided by the span length; NaN if the track is not curved |
| `glideRatio` | horizontal displacement / height lost over $W$ |
| `coneAngleDeg` $\bar\gamma$ | mean of $\arccos\lvert\hat n\cdot\hat Y\rvert$: plate normal from vertical (0° broadside, 90° edge-on) |
| `spanAlongVel` | mean $\lvert\hat s\cdot\hat v\rvert$ |

## 2. The six parts

Each part is judged on its own. Boundaries come from `defaultSeedModeThresholds`.

**Decided 2026-10-03**, from the by-eye review set
`Outputs/Classifier Review/2026-09-27_165346_3727986`:

- the 1-span tight/wide radius;
- the 70° end-on threshold;
- the 0.25 glide ratio;
- wobbling spin and chaotic are non-physical.

**Decided 2026-10-05**: the flip boundary is **0.10 turn (36°)** peak-to-peak, raised
from a judged 0.05 (18°). Revolvers in the Hou et al. window rock 21–30° about the span
while revolving tightly at a steady tilt. That is autorotation with a pitch rock, not a
flutter spiral.

The other boundaries are judgements, to be checked against labels.

**A. Flip**: rotation about the span axis

| value | rule | in words |
|---|---|---|
| `none` | `flipPPTurns` < **0.10** (36°) | the plate does not turn about its span, or only rocks slightly |
| `flutter` | max one-way leg < 1 turn | rocks back and forth, never completes a turn |
| `tumble` | ≥ 1 turn one way, no reversals | continuous end-over-end turns |
| `segmentedTumble` | ≥ 1 turn, with < 3 reversals or reversal CV < 0.35 | whole turns that reverse direction periodically |
| `irregular` | ≥ 1 turn, ≥ 3 reversals, CV ≥ 0.35 | whole turns reversing at irregular times |

**B. Revolution**: about the world vertical

| value | rule | in words |
|---|---|---|
| `none` | $\lvert\dot\phi_s\rvert$ ≤ 5 rad/s | the span heading does not turn |
| `tight` | revolving, radius < **1 span** (or no fitted circle) | turns about an axis within a span of the seed |
| `wide` | revolving, radius ≥ **1 span** | circles on a radius of a span or more |

**C. Attitude**: span axis from horizontal

| value | rule |
|---|---|
| `flat` | mean $\lvert\theta\rvert$ < 30° |
| `steep` | 30° – 70° |
| `endOn` | mean $\lvert\theta\rvert$ > **70°**: span near vertical, falling span-first. **Non-physical.** |

**D. Path**: non-revolving seeds only

| value | rule |
|---|---|
| `steep` | glide ratio ≤ **0.25** |
| `glide` | glide ratio > **0.25** |

**E. Regularity**

| value | rule |
|---|---|
| `chaotic` | flip `irregular`, **or** std of $\theta$ > 25°. **Non-physical.** |
| `wobbling` | std of $\theta$ > 7° (and not chaotic) |
| `steady` | std of $\theta$ ≤ 7° |

**F. Physical**: false for `endOnFall`, `endOnSpin`, `chaotic`, `wobblingSpin`,
`edgeSlide`; true otherwise.

## 3. Mode names — use these for `label_eye`

"No rotation" means flip `none` and revolution `none`. "Edge-on" means $\bar\gamma$ > 45°.
The rules apply in this order, and the **first match wins**.

| # | name | rule | in words | paper |
|---|---|---|---|---|
| 1 | `endOnFall` ⚠ | attitude `endOn`, no rotation | falls span-first, not turning | – |
| 2 | `endOnSpin` ⚠ | attitude `endOn`, flipping or revolving | falls span-first while turning | – |
| 3 | `chaotic` ⚠ | regularity `chaotic` | no sustained pattern; attitude swings or reversals are irregular | CH |
| 4 | `wobblingSpin` ⚠ | regularity `wobbling`, revolving | revolves, but the span axis wobbles widely | – |
| 5 | `edgeSlide` ⚠ | no rotation, edge-on, attitude `flat`, mean $\lvert\hat s\cdot\hat v\rvert$ > 0.5 | slides along its own level span | – |
| 6 | `chordDive` | no rotation, edge-on, attitude `flat` | dives chord edge first, span level | – |
| 7 | `obliqueDive` | no rotation, edge-on, attitude `steep` | dives edge-on with the span tilted | FA |
| 8 | `glide` | no rotation, not edge-on, path `glide` | descends at a shallow attitude, travelling sideways | – |
| 9 | `parachute` | no rotation, not edge-on, path `steep` | falls broadside, nearly straight down | – |
| 10 | `autorotation` | flip `none`, revolution `tight` | revolves about an axis within a span of the seed, no flip | AR |
| 11 | `spiralGlide` | flip `none`, revolution `wide` | circles on a radius of a span or more, no flip | – |
| 12 | `flutter` | flip `flutter`, revolution `none`, path `steep` | rocks about the span, falls nearly straight down | FL |
| 13 | `flutterGlide` | flip `flutter`, revolution `none`, path `glide` | rocks about the span, travelling sideways | FL |
| 14 | `flutterSpiral` | flip `flutter`, revolving (any radius) | rocks about the span while revolving | – |
| 15 | `tumble` | flip `tumble`/`segmentedTumble`, revolution `none` | turns end-over-end, no revolution | – |
| 16 | `tightSpiralTumble` | tumbling, revolution `tight` | tumbles while revolving within a span | CST/SST |
| 17 | `spiralTumble` | tumbling, revolution `wide` | tumbles while circling on a radius of a span or more | CST/SST |
| – | `unsure` | eye label only | can't tell; say why in `notes_eye` | – |

⚠ = non-physical: a motion real seeds do not show. These count as **disagreements** in any
score, and their share of a grid is a tracked metric that should go to zero. End-on and edge
modes come from strip theory discarding spanwise flow (research log, phase 6). Wobbling spin
and chaotic were judged non-physical on the review footage.

> **Note on `chaotic`.** Hou et al. (2025) report a chaotic mode (CH) experimentally. The
> non-physical call here is about the chaotic motion *this model* produces in the review
> set, not a claim that real plates never behave chaotically.

**Seen in the review set and worth re-watching:**

| run(s) | what to check |
|---|---|
| R043 | span at 68.7°, just under end-on |
| R037 | span at exactly 70.0° |
| R066, R004 | periodic segmented tumbling with no revolution, which reads as `tumble`; you labelled chaotic and dive |
| R024, R025 | glide ratio 0.51 and 0.97, so `flutterGlide` under the 0.25 rule |

## 4. Older classifier A: `classifyFlightMode` (our seed)

Kept for comparing with earlier runs. Thresholds (`defaultModeThresholds`):

| threshold | value |
|---|---|
| `spinLo` | 5 rad/s |
| `vSpinAuto` | 10 rad/s |
| `tiltSteady` | 5° |
| `tiltChaos` | 30° |
| `helixTight` | 0.05 m |
| `glideHi` | 1.0 |
| `coneEdge` | 45° |
| `coneBroad` | 20° |

Write $\Omega_V$ = mean $\lvert(R\boldsymbol\omega)\cdot\hat Y\rvert$ (spin about the vertical),
$\Omega_s$ = mean $\lvert\omega_z\rvert$, and $\sigma_\gamma$ = std of the plate-normal tilt.
Let spinning = $\Omega_V$ > 5 or $\Omega_s$ > 5. The rules apply in order; the first match
wins:

| # | label | rule |
|---|---|---|
| 1 | `chaotic` | not converged, $\Omega_V$ < 10, $\sigma_\gamma$ > 30° |
| 2 | `gliding` | not spinning, glide ratio > 1 |
| 3 | `diving` | not spinning, $\bar\gamma$ > 45° |
| 4 | `parachuting` | not spinning, $\bar\gamma$ < 20° |
| 5 | `undetermined` | not spinning, otherwise |
| 6 | `autorotation` | $\Omega_V$ > 10, $\sigma_\gamma$ < 5° |
| 7 | `tightSpiral` | $\Omega_V$ > 10, helix radius < 0.05 m |
| 8 | `spiral` | $\Omega_V$ > 10, otherwise |
| 9 | `fluttering` | spinning, $\Omega_V$ ≤ 10 |

**Known defects:**

- `fluttering` lumps rocking with tumbling.
- `spinning` reads raw $\lvert\omega_z\rvert$, so a tilted revolution counts as spin about
  the span.
- Attitude is the plate normal only, so `diving` cannot tell chord-first from span-first.
- Calibrated on 7 planar reference inputs.

## 5. Older classifier B: `classifyPaperMode` (Hou et al. 2025)

Kept for the paper comparison. It uses the orbital revolution rate $\dot\phi$ (from the CoM
ground track, measured about $+\hat Y$) and the self-rotation
$\dot\psi=\omega_z-\dot\phi\sin\theta$.

> **Sign fix, 2026-10-03.** $\dot\phi$ was measured about $-\hat Y$, the opposite sense to
> $\boldsymbol\omega\cdot\hat Y$, so for a steady revolver $\dot\psi$ came out at twice the
> revolution's projection instead of zero. Every steady revolver read as `CST`. The
> synthetic test had the matching flip and passed. Both are fixed, and the synthetic orbit is
> now generated by the same rotation as the attitude. All paper-classifier results before
> this date are affected.

Thresholds (`defaultPaperThresholds`):

| threshold | value |
|---|---|
| `tumbleTurnsST` | 1 turn |
| `tumbleRateST` | 5 rad/s |
| `tiltStdSegmented` | 7° |
| `vSpinAR` | 10 rad/s |
| `tiltStdAR` | 10° |
| `tiltStdChaos` | 25° |

Let tumbling = max one-way $\dot\psi$ turns > 1 **and** mean $\lvert\dot\psi\rvert$ > 5; let
revolving = $\Omega_V$ > 10; and let steady = std of $\theta$ < 10°. The rules apply in
order; the first match wins:

| # | label | rule |
|---|---|---|
| 1 | `SST` | tumbling, with reversals or std of $\theta$ > 7° |
| 2 | `CST` | tumbling, otherwise |
| 3 | `CH` | std of $\theta$ > 25° |
| 4 | `CH` | not converged, std of $\theta$ > 7° |
| 5 | `AR` | revolving, steady |
| 6 | `CH` | revolving, otherwise |
| 7 | `FL` | mean $\lvert\dot\psi\rvert$ > 5, max one-way < 1 turn |
| 8 | `FA` | otherwise |

**Known defects:**

- ST does not require revolution, so a plain tumble reads as `CST`.
- FA is a catch-all that includes the span-first fall.

## 6. Template for a new mode

1. Add a row to the section 3 table:

   ```
   | n | `newLabel` | rule (or "–" until defined) | what you SEE, in one sentence | paper equivalent or – |
   ```

2. Note one example run (review folder + `run_id`) below the table, so the definition can be
   checked against footage.
3. When the rule is settled, add it to `classifySeedMode.m`. Put any new boundary value in
   `defaultSeedModeThresholds.m`, with its date. Add a synthetic case to
   `testing/shape3d/testPaperMetrics.m`.
4. Add an idealized example to the case table in `testing/classifier/makeModeExamples.m`,
   using `synthSeedMotion` parameters. Re-run the script: its self-check refuses to render
   an example that doesn't classify as its own label.
